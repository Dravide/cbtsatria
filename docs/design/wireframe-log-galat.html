Wireframe Sistem Log Galat Terkode (Database)

Rancangan pencatatan otomatis setiap galat aplikasi (500, 403, 419, exception tak tertangani, dan job gagal) ke tabel error_logs di basis data, lengkap dengan kode unik per area portal seperti ER-ADM-001 dan ER-GR-001 agar pelaporan masalah dari lapangan langsung menunjuk ke insiden yang tepat.

Plate 01 — Taksonomi Kode Galat & Struktur Tabel error_logs

Aturan Penomoran · Database & Exception Handler

Prefix Kode Berdasarkan Portal / Rute

Format: ER-{PORTAL}-{NO}
Prefix Area / Rute Contoh Kode Sasaran Pengguna
ER-ADM /admin/* ER-ADM-001 Admin Sekolah
ER-GR /guru/* ER-GR-001 Guru / Penulis Soal
ER-PGW /pengawas/*, /p/* ER-PGW-001 Pengawas Ruang
ER-SSW /siswa/*, /hadir/* ER-SSW-001 Siswa / Peserta Ujian
ER-SUP /super/* ER-SUP-001 Super Admin Platform
ER-PUB /login, /jadwal/*, /tv/*, /wali/* ER-PUB-001 Publik / Tamu / Wali
ER-SYS Queue Job, Scheduler, Artisan CLI ER-SYS-001 Latar Belakang Sistem

Skema Ringkas Tabel error_logs

MySQL · Deduplikasi
code
ER-ADM-001 (unik, nomor urut per prefix)
portal
ADM | GR | PGW | SSW | SUP | PUB | SYS
fingerprint
SHA-1(exception + file + line + route) — agar galat yang sama berulang tidak memenuhi tabel, cukup naikkan occurrences
status_code
500, 419, 403, 404 (opsional/terfilter)
exception
Nama kelas & pesan error lengkap
location
file + line + ringkasan trace
context
school_id, user_id, url, method, ip, payload_sanitized
resolution
resolved_at, resolved_by, resolution_note

Pengaman DB & Privasi: (1) Jika koneksi database sendiri yang bermasalah saat mencatat log, exception logger otomatis jatuh kembali ke laravel.log agar tidak memicu loop error. (2) Field sensitif (password, _token, api_key, code) disensor menjadi [REDACTED] sebelum masuk DB. (3) Deduplikasi memakai fingerprint: jika ER-ADM-001 terjadi 12 kali untuk bug yang sama dan belum ditandai selesai, barisnya tetap satu dengan penghitung occurrences = 12.
